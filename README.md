# MacOS Utilities

Personal MacOS desktop utilities.

## [clean-screen](https://github.com/hunterphillips/clean-screen)

One shortcut (`⌃⌥⌘C`) hides the menu bar, Dock, desktop icons, and optionally
all app windows, then restores them exactly.

![clean-screen before and after](https://raw.githubusercontent.com/hunterphillips/clean-screen/main/assets/before-after.png)

## [restore-layout](https://github.com/hunterphillips/restore-layout)

Save your window layout once; one shortcut (`⌃⌥⌘R`) puts every window back
after a monitor unplug or a maximized window scrambles things.

![restore-layout before and after](https://raw.githubusercontent.com/hunterphillips/restore-layout/main/assets/before-after.png)
