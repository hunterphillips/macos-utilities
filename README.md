# utilities

Small macOS menu bar utilities I built for my own workflow. Each one is a
separate repo; this page is the index.

## [clean-screen](https://github.com/hunterphillips/clean-screen)

Toggles a clean screen with one shortcut (`⌃⌥⌘C`): hides the menu bar, Dock,
desktop icons, and optionally all app windows, then restores them exactly.

![clean-screen before and after](https://raw.githubusercontent.com/hunterphillips/clean-screen/main/assets/before-after.png)

## [restore-layout](https://github.com/hunterphillips/restore-layout)

Saves your window layout once, then puts every window back on the built-in
display with one shortcut (`⌃⌥⌘R`) after a monitor unplug or a maximized
window scrambles things.

![restore-layout before and after](https://raw.githubusercontent.com/hunterphillips/restore-layout/main/assets/before-after.png)
